Le même principe que le schéma ci-dessus, en une classe d'une dizaine de lignes.

définition de la classe 
class SimpleAgent:
    def __init__(self, outils):
        self.outils = outils
        self.memoire = []

    def run(self, requete):
        requete_minuscule = requete.lower()
        if 'météo' in requete_minuscule:
            # Appeler l'outil météo
            resultat = self.outils['météo']()
            # Sauvegarder dans la mémoire
            self.memoire.append({
                'requete': requete,
                'outil': 'météo',
                'resultat': resultat
            })
            # Formater la réponse finale
            return f'Météo : {resultat}'
        else:
            return "Aucun outil nécessaire."
exécution 
def obtenir_meteo():
    return "28°C, Partiellement Nuageux"

agent = SimpleAgent(outils={'météo': obtenir_meteo})
requete = "Quel temps fait-il à Bangalore aujourd'hui ?"
reponse = agent.run(requete)
print(reponse)
Sortie → Météo : 28°C, Partiellement Nuageux
Fig. 05

Ce qui rend un agent puissant

Autonomie

Planifie des tâches et passe à l'action avec un minimum de guidage humain.

Appel d'outil

Interagit avec des systèmes externes : API, recherche, calculatrice, bases de données.

Mémoire

Se souvient des interactions passées et réutilise le contexte précédent.

Raisonnement

Divise les tâches, planifie les actions, et s'adapte en fonction des résultats.
