Objectif

The $0 AI Architecture Stack

À la fin de ce cours, vous serez capable de décomposer une application IA autonome en couches, de sélectionner des briques locales ou gratuites et de planifier un déploiement souverain.

Le paradigme

Des modèles open-weights locaux, des protocoles ouverts et des paliers gratuits peuvent former une architecture de production sans abonnement API obligatoire.

La règle d’ingénierie

Le coût nul ne signifie pas absence d’architecture : il faut toujours penser routage, persistance, sécurité, observabilité et limites matérielles.

Architecture

Lire la stack de bas en haut

1. Frontend

Next.js + Vercel Free Tier pour la production web, ou Streamlit pour prototyper rapidement en Python.

2. Orchestrateur

LangGraph formalise les états, transitions conditionnelles, boucles d’évaluation et re-planning ; CrewAI distribue des rôles spécialisés.

3. RAG

ChromaDB ou Qdrant récupèrent les données privées ou fraîches lorsque le routage l’exige.

4. LLM local

Ollama sert Gemma pour le routage, Mistral pour le raisonnement multilingue ou Llama 3.3 70B quantifié pour les dossiers lourds.

Outillage

Donner des outils au modèle sans connecteurs ad hoc

MCP standardise l’exposition de Tools, Prompts et Resources. Les agents de code peuvent ensuite naviguer dans le dépôt, modifier des fichiers, tester et corriger, sous contrôle de l’orchestrateur.

Tools

Actions exécutables : Git, fichiers, SQLite ou notifications.

Resources

Données accessibles avec une adresse et un schéma explicites.

Prompts

Gabarits réutilisables exposés de manière standardisée.

Fiabilité

Persister et observer l’exécution

SQLite stocke l’historique et l’état local, DuckDB accélère l’analyse de logs et Supabase Free fournit une option PostgreSQL gérée. Le checkpointing permet de reprendre après une défaillance.

Phoenix, instrumenté avec OpenTelemetry, trace les nœuds LangGraph, la latence, les tokens, les requêtes vectorielles et les évaluations de groundedness.

Atelier

Planifier le déploiement en quatre étapes

  1. Calcul & inférence : installer Ollama, l’accélération matérielle et les poids.
  2. Stockage vectoriel : lancer Qdrant, choisir la distance cosinus et connecter le parsing.
  3. Orchestration : développer le StateGraph avec routage, retrieval et MCP.
  4. Monitoring : activer Phoenix sur le port local 6006 avant les premiers essais.
