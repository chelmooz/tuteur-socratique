Introduction

Comprendre l’Architecture Transformer

Le moteur des IA modernes, expliqué du texte d’entrée jusqu’au prochain token généré.

Les Transformers remplacent la lecture strictement séquentielle par une attention qui compare les éléments de la séquence. L’encodeur comprend une entrée ; le décodeur produit une sortie token par token.

Quiz express

Quelle est l’idée centrale du Transformer ?

Étape 1

Tokens, embeddings et position

Le texte est découpé en tokens puis transformé en vecteurs. L’embedding place des mots proches par le sens dans des régions voisines de l’espace vectoriel.

Tokenisation

Un mot peut être représenté par un mot entier ou plusieurs sous-mots.

Embedding

Chaque token devient un vecteur numérique exploitable par le réseau.

Encodage positionnel

Il ajoute l’ordre, nécessaire pour distinguer « le chat mange » de « la souris mange ».

Texte → tokens → vecteurs
[Le, chat, mange] → [e₁, e₂, e₃]
representation = embedding(token) + position(token)

Étape 2

Le bloc encodeur — comprendre le contexte

L’encodeur affine la représentation de l’entrée à travers plusieurs blocs répétés.

Multi-Head Attention

Chaque token compare sa signification aux autres ; différentes têtes captent grammaire, accords ou relations.

Feed-Forward

Réseau appliqué à chaque position pour transformer les caractéristiques extraites.

Add & Norm

Connexions résiduelles et normalisation pour stabiliser l’apprentissage.

N ×

Le bloc est empilé plusieurs fois pour des représentations plus abstraites.

Étape 3

Le bloc décodeur — générer sans regarder le futur

Le décodeur utilise les tokens déjà produits et les représentations de l’encodeur pour générer le token suivant.

Attention masquée

Le masque empêche de consulter les tokens futurs pendant la prédiction.

Cross-attention

Le décodeur interroge la sortie de l’encodeur pour relier ce qu’il écrit à la source.

Génération auto-régressive

Le token produit est réinjecté pour prédire le suivant.

Déjà généré : Le chat
Masque : ne pas voir le futur
Cross-attention : consulter la source
Prédit : mange
Puis : Le chat mange ...

Étape 4

Couche linéaire, softmax et prochain token

Le dernier vecteur est projeté sur le vocabulaire. La couche linéaire produit des scores ; le softmax les transforme en probabilités. Le modèle choisit ou échantillonne un token selon la température.

h_final → Linear(vocabulaire) → logits
logits → Softmax → probabilités
["mange": 0.62, "dort": 0.21, "court": 0.08, ...]
choisir/échantillonner → réinjecter le token
