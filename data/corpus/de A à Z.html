IA vs Machine Learning vs Informatique Classique

L'IA permet aux machines d'effectuer des tâches nécessitant l'intelligence humaine (reconnaissance de formes, parole, image). Mais toute IA n'est pas du Machine Learning. Les systèmes à base de règles, l'algorithme A* (GPS), ou la logique floue (frigos, climatiseurs) sont de l'IA, mais pas du ML. ⏱ 4:03

Informatique Classique

Input + Logique (Code) → Output. Le programmeur écrit les règles explicites.

Machine Learning

Input + Output (Données) → Logique (Modèle). La machine découvre les règles elle-même en analysant les données.

Les deux phases du ML : Entraînement et Inférence

Prenons l'exemple d'une banque qui doit décider d'accorder un prêt. 1. Entraînement : On analyse l'historique (credit score, salaire, âge) pour trouver des patterns et créer une "formule" (le modèle). 2. Inférence : Un nouveau client arrive, on applique la formule pour prédire s'il sera accepté ou rejeté. ⏱ 7:44

Quiz express

1. Lequel de ces éléments est de l'IA mais PAS du Machine Learning ?

A* est un algorithme de recherche de graphe basé sur des règles explicites, pas sur l'apprentissage à partir de données.

2. Que produit la phase d'entraînement en ML ?

L'entraînement analyse les données pour extraire la logique. L'inférence utilise ce modèle pour faire des prédictions.

Les 3 piliers du Machine Learning

1. Apprentissage Supervisé (Données étiquetées)

On fournit à la machine des Inputs ($x$) et les Outputs attendus ($y$). Le but est de trouver la fonction $y = f(x)$. ⏱ 13:20

Classification

Prédire une catégorie. Binaire (Spam/Non-spam, Prêt accepté/refusé) ou Multi-classe (Sentiment Pos/Neg/Neutre, Reconnaissance de chiffres 0-9).

Régression

Prédire une valeur numérique continue. Ex: Temps de livraison (Zomato/Swiggy), Prix de l'immobilier, Température. ⏱ 20:09

2. Apprentissage Non-Supervisé (Données brutes)

Pas d'étiquettes. La machine doit trouver des structures cachées, des patterns. ⏱ 23:29

Clustering

Grouper des données similaires. Ex: Regrouper des articles de news (Tech, Politique, Sport). Partitionnel (K-Means) ou Hiérarchique.

Détection d'anomalies

Trouver les "outliers". Ex: Une carte bancaire utilisée dans 5 pays en 1 heure (Fraude/Cybersécurité). ⏱ 24:51

Association

Trouver des liens entre entités. Ex: Market Basket Analysis (les gens qui achètent du pain achètent aussi du lait). ⏱ 27:31

3. Apprentissage par Renforcement (Trial & Error)

Un Agent interagit avec un Environnement. Il reçoit des Récompenses (positif) ou des Pénalités (négatif). Son but n'est pas d'avoir raison une fois, mais de maximiser la récompense totale sur la durée. C'est comme dresser un chien avec des friandises. Ex: AlphaGo (Échecs/Go), Voitures autonomes, Robotique. ⏱ 28:47

Deep Learning : Le Neurone Artificiel

Le ML statistique (régression, arbres) excelle sur les données tabulaires. Mais pour les données non structurées (images, audio, texte), extraire les features manuellement est impossible. Le Deep Learning utilise des Réseaux de Neurones inspirés du cerveau humain pour extraire automatiquement ces features. ⏱ 33:24

Analogie : Le calcul du CGPA

Comment un collège calcule-t-il la note finale ? Il prend les notes des examens (Inputs), les multiplie par leur importance (Poids/Weights), et ajoute un bonus de base (Biais). Un neurone artificiel fait exactement la même chose : Somme Pondérée + Biais, puis passe le tout dans une Fonction d'Activation (Sigmoid, ReLU) pour introduire de la non-linéarité. ⏱ 37:55

Forward & Backward Propagation

1. Forward Propagation

Les données traversent le réseau de gauche à droite, de couche en couche, jusqu'à produire une prédiction (un "guess"). ⏱ 41:34

2. Loss Function

On compare la prédiction avec la vraie réponse (Expected Value). La différence est l'erreur (Loss).

3. Backward Propagation

On repart de la fin vers le début pour ajuster les Poids et les Biais afin de minimiser la Loss. C'est l'apprentissage par l'erreur. ⏱ 45:10

Quiz express

1. Pourquoi le Deep Learning est-il meilleur pour les images que le ML classique ?

Programmer manuellement ce qu'est un "oeil" ou un "nez" en pixels est quasi impossible. Le DL l'apprend seul.

2. Le but de la Backward Propagation est de...

C'est le mécanisme d'apprentissage : apprendre de ses erreurs.

Les 4 Grandes Architectures de Réseaux

FNN (Feedforward)

Le plus simple. L'information va dans un seul sens. Pas de mémoire. Bon pour les données tabulaires simples (Diagnostic médical, Prêt bancaire). ⏱ 48:47

RNN (Recurrent)

Possède une "mémoire" (boucles). Garde le contexte des étapes précédentes. Idéal pour les séquences (Texte, Séries temporelles, Traduction). Limité par la mémoire court-terme (d'où les LSTM). ⏱ 49:57

CNN (Convolutional)

Le roi de l'image. Au lieu de connecter chaque pixel à chaque neurone (trop lourd), il utilise des filtres (kernels) qui glissent sur l'image pour détecter des bords, des textures, des formes. ⏱ 51:16

Transformers

Le moteur de ChatGPT. Remplace les RNN. Utilise le mécanisme d'Attention pour analyser toute la séquence d'un coup et comprendre les relations à longue distance. ⏱ 56:08

Quiz express

1. Quelle architecture est la plus adaptée pour la reconnaissance d'objets dans une vidéo ?

Les CNN sont optimisés pour les données en grille (pixels) et l'extraction de features spatiales.

2. Quel mécanisme permet aux Transformers de comprendre le contexte sans boucles (RNN) ?

GenAI, NLP et Computer Vision

Generative AI

Contrairement au ML classique qui classe ou prédit, la GenAI crée du nouveau contenu (Texte, Image, Audio, Vidéo, Code). Ex: Midjourney, Sora, GitHub Copilot. ⏱ 58:15

NLP (Natural Language Processing)

Le domaine de l'IA qui traite le langage humain. Les LLMs (Large Language Models) comme GPT-4 ou Llama sont des modèles de NLP entraînés sur des trilliards de mots avec des milliards de paramètres. ⏱ 1:00:42

RLHF

Reinforcement Learning from Human Feedback. Technique utilisée par OpenAI pour "dresser" le LLM à ne pas être toxique et à répondre de manière utile, en utilisant des récompenses humaines. ⏱ 1:03:18

Computer Vision

Permettre aux machines de "voir". Utilise massivement les CNN pour la reconnaissance faciale, les voitures autonomes, l'analyse médicale. ⏱ 1:04:12

2. À quoi sert le RLHF dans l'entraînement d'un LLM comme ChatGPT ?

Flashcards

      
IA vs ML
L'IA est le concept global (tâches cognitives). Le ML est le sous-ensemble qui apprend à partir de données au lieu d'être programmé explicitement.

      
Entraînement vs Inférence
Entraînement = apprendre les patterns sur des données passées. Inférence = utiliser le modèle entraîné pour prédire sur de nouvelles données.

      
Supervisé
Données étiquetées ($x \to y$). Classification (catégories) ou Régression (nombres).

      
Non-supervisé
Données brutes. Clustering (groupes), Association (règles de panier), Anomalies (outliers).

      
Renforcement
Agent + Environnement + Récompenses/Pénalités. But : maximiser le score total (Ex: Jeux, Robotique).

      
Deep Learning
Sous-ensemble du ML utilisant des réseaux de neurones pour traiter des données non structurées (images, texte).

      
Neurone Artificiel
Calcule une somme pondérée des entrées + biais, puis applique une fonction d'activation (ReLU, Sigmoid).

      
Backpropagation
Algorithme qui calcule le gradient de l'erreur (Loss) pour ajuster les poids du réseau de la fin vers le début.

      
CNN (Convolutional)
Utilise des filtres glissants pour analyser les images. Réduit massivement le nombre de paramètres par rapport aux FNN.

      
RNN / LSTM
Réseaux récurrents avec mémoire. Idéaux pour les séquences temporelles et le texte, mais limités en mémoire long-terme (d'où LSTM).

      
Transformers
Architecture moderne (GPT) basée sur l'Attention. Analyse toute la séquence en parallèle pour comprendre le contexte global.

      
LLM
Large Language Model. Réseau de neurones géant entraîné sur internet, capable de NLP (compréhension et génération de texte).

      
RLHF
Reinforcement Learning from Human Feedback. Dressage du LLM par des humains pour le rendre sûr et utile.

1. Le Machine Learning se distingue de l'informatique classique car...

Deux catégories distinctes, avec des données étiquetées.

        
3. Grouper des articles de presse par thématique sans étiquettes préalables est...
La machine doit trouver la structure cachée seule.

        
4. Dans un réseau de neurones, que fait la Backward Propagation ?
C'est le cœur de l'apprentissage par correction d'erreur.

        
5. Pourquoi utilise-t-on des CNN pour les images plutôt que des FNN ?
Connecter chaque pixel d'une image HD à chaque neurone est computationnellement impossible.

C'est ce qui permet de savoir à qui se réfère un pronom loin dans la phrase.

Ils apprennent par essai/erreur pour maximiser une récompense (gagner/arriver à destination).

        
8. Qu'est-ce qu'un LLM ?
Large Language Model (ex: GPT, Llama, Claude).

        
9. À quoi sert le RLHF ?
Reinforcement Learning from Human Feedback.

        
10. Lequel de ces outils est un modèle de Computer Vision générative ?
Ils génèrent des images à partir de prompts texte.
