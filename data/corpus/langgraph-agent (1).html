Que construisons-nous ?

Un Agent d'IA de Recherche Approfondie qui peut :

  • Comprendre la question de recherche
  • Créer un plan de recherche
  • Générer des requêtes de recherche
  • Effectuer une recherche sur le web (Tavily)
  • Analyser les résultats
  • Décider si plus de recherches sont nécessaires
  • Générer la réponse finale
Au lieu d'un seul appel LLM, nous construisons un flux de recherche complet.
Un agent, c'est un LLM + un environnement (ici : le web) + un jeu d'outils (ici : Tavily) + une boucle qui décide seule si elle doit continuer ou s'arrêter.

Créer un Environnement Virtuel

  1. Créer un dossier de projet
    mkdir deep-research-agent cd deep-research-agent
  2. Créer un environnement virtuel
    python -m venv .venv
  3. L'activer
    macOS / Linux :
    source .venv/bin/activate
    Windows :
    .venv\Scripts\activate
Vous devriez voir (.venv) dans votre terminal.
5

Installer les Dépendances

Nous avons besoin de :

  • LangGraph
  • Intégration LangChain's OpenAI
  • python-dotenv
  • Client Python Tavily
python -m pip install \ langgraph langchain-openai \ python-dotenv tavily-python
6

Configurer les Clés API

  1. Créer un fichier .env
  2. Ajouter vos clés API :
    OPENAI_API_KEY=votre_clé_openai TAVILY_API_KEY=votre_clé_tavily
  • Chargez-les en utilisant load_dotenv()
  • Ne validez pas votre fichier .env sur GitHub.
  • Ajoutez .env à votre fichier .gitignore.
Gardez vos clés API privées !
