Les 5 blocs de construction d’un bon prompt

Le transcript propose cinq éléments à considérer dans un prompt : goal, input, output, layout, special instructions. Tu n’es pas obligé de tous les utiliser à chaque fois, mais ils structurent ta pensée. ⏱ 4:11

1. Goal

Ce que tu veux créer. Exemple : « create a web page to help me write birthday cards ». ⏱ 4:15

2. Input

Ce que l’utilisateur doit fournir. Exemple : name, age, hobby. ⏱ 4:20

3. Output

Ce que le logiciel doit produire. Exemple : un message drôle de carte d’anniversaire. ⏱ 4:28

4. Layout

Comment organiser l’écran : gauche, droite, carte, formulaire, titre. ⏱ 4:31

5. Special instructions

Fonctionnalités supplémentaires : couleurs, bouton copier, I’m feeling lucky, thème, etc. ⏱ 4:37

Prompt long en une fois

Si tu sais déjà ce que tu veux, tu peux mettre les cinq blocs dans un seul prompt plus long. Sinon, tu peux commencer par le goal, puis ajouter input/output/layout/features au fil de la conversation. ⏱ 5:22

Quiz express

Itérer, préciser, déboguer, demander du feedback

Le transcript insiste : on ne cherche pas la perfection du premier coup. On parle à l’IA comme à un collaborateur : on précise, on corrige, on améliore.

Analogie food truck

« Give me a sandwich » est vague. « Vegetarian sandwich with hummus, cheese, multigrain bread, drink, to go » est précis. Résultat plus prévisible. ⏱ 13:44

Variabilité normale

Même prompt précis, résultats légèrement différents. Si ça surprend, donne des instructions supplémentaires pour orienter l’IA. ⏱ 8:04

Bugs

Décris le symptôme clairement. Tu n’as pas besoin de comprendre les termes techniques ; demande juste le fix. ⏱ 17:45

Feedback humain

Montrer l’app à des amis, famille, collègues. Leurs suggestions rendent le logiciel meilleur et te motivent. ⏱ 11:51

Workflow recommandé

  1. Décris le goal.
  2. Ajoute input/output si tu les connais.
  3. Génère une première version.
  4. Ouvre le fichier HTML dans le navigateur.
  5. Teste, observe ce qui manque ou casse.
  6. Donne une instruction précise : layout, couleur, bouton, bug fix.
  7. Montre à quelqu’un et recommence.

Anti-patterns du vibe coding

Prompt trop vague

« Create a birthday app » sans input/output/layout donne des résultats très variables.

Vouloir tout parfait du premier coup

Le transcript encourage à commencer imparfait et à itérer.

Ne pas tester dans le navigateur

Le fichier HTML doit être téléchargé et ouvert pour voir le vrai comportement.

Paniquer devant un bug

Décris le symptôme à l’IA ; pas besoin de comprendre le jargon technique.

Garder l’app pour soi

Le feedback humain est une étape clé pour améliorer et rester motivé.

Croire que la compétence est liée à une plateforme

Les mêmes prompts fonctionnent sur ChatGPT, Gemini, Claude, ou d’autres systèmes.
