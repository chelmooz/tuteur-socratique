RAG multimodal : deux architectures

Comment rendre les images d’un PDF « cherchables » comme du texte.

Un RAG classique retrouve des passages textuels. Or un PDF contient aussi des graphiques, schémas, tableaux et images. Il faut donc choisir comment représenter ces éléments avant de les rechercher.

Les cinq étapes communes : collecte du PDF → extraction texte/images → mise en mémoire → question et recherche → synthèse par un LLM multimodal.

Quiz

Quelle est la question centrale du RAG multimodal ?

A • Deux bases

Empreintes multimodales et bases séparées

Les images extraites sont encodées par un modèle multimodal et stockées dans une base vectorielle dédiée. Les textes disposent de leur propre pipeline d’embeddings textuels et de base.

Recherche images

Image extraite → empreinte multimodale → base image → images pertinentes.

Recherche textes

Texte extrait → empreinte textuelle → base texte → passages pertinents.

Les deux résultats sont réunis pour la synthèse par le LLM multimodal.

Quel est le principal avantage de l’architecture A ?

B • Base combinée

Résumés d’images et base vectorielle unifiée

Un LLM multimodal décrit chaque image en texte. Ces résumés sont vectorisés comme les autres passages et rangés dans une base commune avec les textes du PDF.

Images

Image extraite → LLM multimodal → résumé textuel → embedding textuel.

Retrieveur multi-vecteurs

Une recherche et un espace communs pour textes et descriptions d’images.

Lorsque le résumé est retrouvé, l’application peut récupérer l’image originale pour l’afficher au LLM.

Cas d’usage

Choisir avec une règle simple

Choisir A si…

Les diagrammes, tableaux, positions spatiales ou détails visuels sont critiques ; vous disposez d’un LLM multimodal et acceptez deux bases.

Choisir B si…

La simplicité opérationnelle prime, les images peuvent être décrites fidèlement et un embedding textuel commun facilite la recherche.

Analogie : A = deux catalogues, photos et fiches séparés, consultés ensemble. B = un catalogue unique où un expert rédige une fiche pour chaque tableau.
