Quand créer son propre harnais d'agent ?

Pour comprendre l'intelligence d'un agent, il faut la décomposer en trois piliers : le modèle, le contexte, et le harnais.

1. L'architecture du Harnais

Le harnais est l'infrastructure qui enveloppe le modèle. Son travail principal est d'apporter le bon contexte au moment opportun.

2. Boucle vs Middlewares

Plutôt que de modifier le modèle, on personnalise la boucle de base via des hooks (middlewares).

  • before_model : Préparer et nettoyer le contexte.
  • wrap_tool_call : Gérer les appels d'outils de façon sécurisée et relancer la boucle (ligne pointillée).
  • after_model : Filtrer ou structurer la sortie finale.

3. Évaluation Continue avec Harbor

Pour savoir si votre harnais (ou vos middlewares) améliore réellement l'agent, il est nécessaire de mettre en place un framework d'évaluation (evals) robuste. Le projet Harbor standardise cette approche de tests.

La Recette de l'Amélioration

  1. Construire un agent V1 et le lancer.
  2. Collecter un volume important de traces.
  3. Explorer et trier ces traces (Data mining).
  4. Lancer des expérimentations ciblées.

Structure d'une Tâche Harbor

  • Environment : Dockerfile ou docker-compose définissant le bac à sable.
  • Instruction : Fichier Markdown décrivant l'objectif pour l'agent.
  • Évaluation : Script (ex: test.sh) vérifiant l'accomplissement.

4. Architectures Cognitives Sur Mesure

Quand l'agent s'éloigne des tâches classiques pour lesquelles le modèle a été entraîné (Out-of-Distribution), une boucle itérative simple montre ses limites (hallucinations, boucles infinies). Il devient nécessaire de concevoir une architecture spécialisée et déterministe pour encadrer le raisonnement de façon stricte.

5. Le Cycle d'Amélioration (Flywheel)

Pour faire évoluer l'agent, le recueil de feedback est crucial. Ce retour d'expérience permet ensuite d'ajuster spécifiquement l'un des trois piliers de l'agent.

1. Collecter le Feedback

  • UX Design : Concevoir une interface qui capte naturellement les corrections de l'utilisateur.
  • Évaluations Synthétiques : Utiliser des petits modèles spécialisés (SLMs), des prompts de vérification ou du code classique pour juger les traces de l'agent.

2. Mettre à jour l'Agent

  • Modèle : Affinement (Finetuning) basé sur les réussites passées.
  • Harnais : Ingénierie du harnais (Harness Engineering) pour corriger les erreurs logiques.
  • Contexte : Enrichissement de la base de connaissances ou de la mémoire.
