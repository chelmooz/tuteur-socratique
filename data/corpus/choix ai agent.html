Les Design Patterns des Agents IA

Le bon modèle. Le bon cas d'usage. Un agent fiable.

La conception de systèmes d'Intelligence Artificielle robustes repose sur le choix de l'architecture appropriée. Ce cours détaille les sept principaux "Design Patterns" (modèles de conception) pour les agents IA, en expliquant leur fonctionnement et leurs cas d'usage optimaux. Comme de coutume dans l'ingénierie IA, nous conserverons la terminologie technique en anglais.

1

Augmented LLM (Single-Shot)

+

Concept

One call, no loop. The model answers directly using retrieval, tools, or short-term memory.

Idéal pour

Le tri, l'extraction de champs, la synthèse de documents et les transformations de données simples et propres.

2

ReAct Loop

+

Concept

Think → Do → Check → Go again. The agent reasons, uses tools, observes results, and re-evaluates until the goal is reached.

Idéal pour

Tâches nécessitant un usage intensif d'outils, recherches dynamiques, problèmes complexes sans chemin de résolution fixe.

3

Router

+

Concept

Read the request first, then send it to the right specialist or model.

Idéal pour

Routage des intentions multiples (mixed-intent flows), rationalisation des coûts à grande échelle.

4

Planner-Executor

+

Concept

Draft a plan, split it into pieces, run them (often in parallel), then combine the results.

Idéal pour

Workflows longs et multicouches nécessitant une décomposition en étapes séquentielles ou parallèles.

5

Evaluator-Optimizer (Reflexive)

+

Concept

Actor/critic approach. One model generates, another critiques, then it's rewritten. Gains flatten after 2–3 rounds.

Idéal pour

Cas d'usage avec forte exigence de qualité (high quality bar) ou lorsque les erreurs coûtent cher.

6

Verifier-Gated

+

Concept

Add a gatekeeper. The agent proposes an action, but an independent check must approve before it executes.

Idéal pour

Paiements, autorisations, conformité légale (compliance) ou actions irréversibles.

7

Multi-Agent + Memory

+

Concept

Specialized agents built on different stacks coordinate via open protocols (like MCP). Backed by governed long-term memory that outlives a single run.

Idéal pour

Systèmes d'entreprise multiplateformes qui doivent persister dans le temps et mémoriser l'état global.
