5 patterns

La matrice des patterns agentiques

1. Tool Use

Appeler des systèmes externes avec function calling JSON typé, FastAPI ou LlamaIndex.

2. Reflection

Évaluer, reclasser, mesurer avec RAGAS/Langfuse et corriger.

3. Plan & Execute

Décomposer et replanifier avec LangGraph ou un DAG.

4. Orchestrator/Worker

Déléguer à des sub-agents et workers au contexte isolé.

5. Memory & Context

Sélectionner mémoire courte, longue, épisodique et chunks pertinents.

Stack technique

Architecture du Curator arXiv

Interface Telegram / Gradio
→ FastAPI Orchestrator
→ LangGraph : plan, replan, choix d’outil
→ Ollama LLM local
→ Hybrid Search : OpenSearch BM25 + vecteurs
→ PostgreSQL + index vectoriel
→ Airflow : fetch, OCR, batch

Le pipeline d’ingestion et l’orchestrateur sont séparés : les tâches lourdes comme téléchargement et OCR s’exécutent sans bloquer l’API.
